## 第一部分：專案實作原始碼 (模組化架構)

為了確保程式碼的可讀性與後續維護性，本專案採用物件導向設計 (OOP)，將不同功能的邏輯拆分為獨立模組。

### 1. `layers.py` (網路層模組)
負責管理權重矩陣、偏差向量，並處理前向傳播與反向傳播的矩陣運算。

```python
import numpy as np

class DenseLayer:
    def __init__(self, input_size, output_size):
        # 初始化權重矩陣 W 和偏差 b，乘以 0.1 避免梯度爆炸
        self.weights = np.random.randn(input_size, output_size) * 0.1
        self.bias = np.zeros((1, output_size))
        
        self.input = None
        
    def forward(self, input_data):
        self.input = input_data
        # 線性組合： Z = XW + b
        return np.dot(self.input, self.weights) + self.bias
        
    def backward(self, output_gradient, learning_rate):
        # 根據連鎖律計算梯度
        weights_gradient = np.dot(self.input.T, output_gradient)
        bias_gradient = np.sum(output_gradient, axis=0, keepdims=True)
        input_gradient = np.dot(output_gradient, self.weights.T)
        
        # 梯度下降法更新參數
        self.weights -= learning_rate * weights_gradient
        self.bias -= learning_rate * bias_gradient
        
        return input_gradient
```

### 2. `activations.py` (激勵函數模組)
提供非線性映射能力，包含前向激活與反向求導。

```python
import numpy as np

class ActivationLayer:
    def __init__(self, activation_type="sigmoid"):
        self.activation_type = activation_type
        self.input = None
        
    def forward(self, input_data):
        self.input = input_data
        if self.activation_type == "sigmoid":
            return 1 / (1 + np.exp(-input_data))
        elif self.activation_type == "relu":
            return np.maximum(0, input_data)
            
    def backward(self, output_gradient, learning_rate):
        if self.activation_type == "sigmoid":
            s = 1 / (1 + np.exp(-self.input))
            return output_gradient * s * (1 - s)
        elif self.activation_type == "relu":
            return output_gradient * (self.input > 0)
```

### 3. `losses.py` (損失函數模組)

```python
import numpy as np

def mse(y_true, y_pred):
    return np.mean(np.power(y_true - y_pred, 2))

def mse_derivative(y_true, y_pred):
    return 2 * (y_pred - y_true) / y_true.size
```

### 4. `network.py` (神經網路主引擎)
負責串接網路層，並執行完整的訓練與預測迴圈。

```python
class NeuralNetwork:
    def __init__(self):
        self.layers = []
        self.loss_history = []
        
    def add(self, layer):
        self.layers.append(layer)
        
    def predict(self, input_data):
        output = input_data
        for layer in self.layers:
            output = layer.forward(output)
        return output
        
    def train(self, x_train, y_train, epochs, learning_rate, loss_fn, loss_der):
        for epoch in range(epochs):
            # 1. 前向傳播
            output = x_train
            for layer in self.layers:
                output = layer.forward(output)
                
            # 計算當前誤差
            current_loss = loss_fn(y_train, output)
            self.loss_history.append(current_loss)
            
            # 2. 反向傳播
            gradient = loss_der(y_train, output)
            for layer in reversed(self.layers):
                gradient = layer.backward(gradient, learning_rate)
                
            # 印出訓練進度
            if (epoch + 1) % (epochs // 10) == 0 or epoch == 0:
                print(f"Epoch {epoch+1}/{epochs} -> Loss: {current_loss:.6f}")
```

## 三、 系統架構與數學推導 (Methodology)

### 3.1 核心架構設計
引擎採用物件導向設計，將系統分為四大模組：
* **`DenseLayer`**：管理每一層的權重 $W$ 與偏差 $b$。
* **`ActivationLayer`**：負責非線性映射（如 Sigmoid, ReLU）與局部導數計算。
* **`Losses`**：評估模型成效（如 MSE）並啟動反向傳播的第一步。
* **`NeuralNetwork`**：網路主體，控制前向與反向資料流的生命週期。

### 3.2 數學原理與反向傳播推導
神經網路的運作依賴嚴謹的矩陣對齊。假設輸入為 $X$，權重為 $W$：

**前向傳播 (Forward Propagation)**：
線性組合輸出 $Z$ 與激勵輸出 $A$ 可表示為：
$$Z = X \cdot W + b$$
$$A = \sigma(Z)$$

**反向傳播 (Backpropagation)**：
根據微積分連鎖律，假設後層傳回的梯度為 $\frac{\partial L}{\partial A}$，則當前層的梯度更新公式為：
1. 對線性輸出 $Z$ 的梯度：$\frac{\partial L}{\partial Z} = \frac{\partial L}{\partial A} \odot \sigma'(Z)$
2. 對權重 $W$ 的梯度：$\frac{\partial L}{\partial W} = X^T \cdot \frac{\partial L}{\partial Z}$
3. 對偏差 $b$ 的梯度：$\frac{\partial L}{\partial b} = \sum \left( \frac{\partial L}{\partial Z} \right)$
4. 傳遞給前一層的梯度：$\frac{\partial L}{\partial X} = \frac{\partial L}{\partial Z} \cdot W^T$
